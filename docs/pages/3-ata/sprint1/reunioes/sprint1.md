## 2. Resumo da Reunião
#### 2.1. Objetivo da Reunião

Apresentação da documentação em que serão centralizadas todas as informações do projeto, do link de deploy dos requisitos conforme forem sendo finalizados e do protótipo do projeto. Por fim, foram abertas discussões para esclarecer dúvidas.

#### 2.2. Pautas da Reunião
| Pauta                                                     |
| --------------------------------------------------------- |
| Apresentação da documentação com as Histórias de Usuário |
| Apresentação do link do site do Stakeholder               |
| Apresentação do Protótipo do site                          |

#### 2.3. Decisões Importantes


- A visualização dos processos no painel inicial será restringida por perfil de permissão, permitindo que gestores visualizem todos os processos e outros usuários apenas aqueles de sua responsabilidade.
- A plataforma será desenvolvida seguindo o padrão mobile-first, garantindo que a interface seja totalmente responsiva tanto para dispositivos móveis quanto para desktop.

##### 2.3.1 Próximos passos

- Alterar o protótipo para permitir a visualização de processos de acordo com o nível de permissão de cada usuário. Implementar a funcionalidade para que gestores visualizem todos os registros enquanto outros usuários acessam apenas os próprios.
- Analisar as funcionalidades de controle de status na plataforma externa DataJ. Confirmar se a ferramenta oferece suporte para a atualização automática de andamentos processuais (Alexandre).
- Disponibilizar a versão atualizada do protótipo para análise detalhada do cliente. Enviar o acesso ao projeto após os ajustes solicitados.
